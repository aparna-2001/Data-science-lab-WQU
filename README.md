# WorldQuant University — Data Science Lab

This repository contains my practice work, notebooks, datasets, and projects completed as part of the **Data Science Lab at WorldQuant University (WQU)**.

The goal of this repository is to document my learning journey and maintain a practical portfolio of data science work, including data analysis, visualization, statistical analysis, and machine learning exercises.

## 📂 Repository Structure

```text
wqu-data-science-lab/
│
├── data/
│   ├── raw/              # Original datasets used for practice
│   └── processed/        # Cleaned or transformed datasets
│
├── notebooks/            # Jupyter notebooks and practice exercises
│
├── projects/             # Completed lab projects
│
├── src/                  # Reusable Python scripts and functions
│
├── reports/              # Reports, findings, and visualizations
│
├── requirements.txt      # Python dependencies
│
└── README.md
```
